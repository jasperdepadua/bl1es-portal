# specs/

Business rules and API contracts — **living documents** that reflect current truth.

- One file per domain (e.g. `grading.md`, `attendance.md`, `enrollment.md`), added as we spec each area.
- **API contracts** (request/response shapes, Supabase table + RLS expectations) live here too.
- Source material (DepEd Order, classroom orientation deck) is *interpreted* into these specs — the
  original PDFs are read-only references, never edited into rules directly.
- **`reference-findings.md`** — raw factual extraction from the source PDFs. Not decided rules
  itself; the input the per-domain specs get interpreted from.

Part 2 of planning. Updated anytime as rules evolve.
