# design-system/

The visual foundation of the portal.

- **Palette → design tokens** (CSS variables): primary, secondary, accent, neutrals, semantic colors.
- **Typography** scale, **spacing**, **radius**, **elevation**.
- **Component conventions** — how shared UI components look and behave.

Kicks off once the color palette and desired "vibe" are locked. Feeds directly into the Tailwind
theme configuration.
